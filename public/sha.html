SHA-1 vs SHA-256 vs SHA-384 vs SHA-512

SHA-1 produces a 160-bit hash (40 hex characters) and is now considered weak. SHA-256 produces 256 bits (64 hex characters), SHA-384 produces 384 bits, and SHA-512 produces 512 bits. For new work, use SHA-256 or stronger.

Common SHA use cases

  • Verify file integrity with checksums.
  • Generate content identifiers for git, blockchains, and APIs.
  • Fingerprint text or data for comparison.

Security note

SHA hashes are not designed for password storage. Use bcrypt, Argon2, or scrypt for passwords.

FAQ

What is a SHA-256 hash?

A SHA-256 hash is a 256-bit fingerprint of data, usually shown as 64 hexadecimal characters.

Is SHA-1 still secure?

No. SHA-1 is considered weak and should be replaced with SHA-256 or stronger for any new system.

Can I use SHA-256 for passwords?

No. SHA-256 is a fast hash and is not designed for passwords. Use bcrypt, Argon2, or scrypt instead.
