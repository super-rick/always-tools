What are HTML entities?

HTML entities are special codes that represent reserved characters. For example, &lt; displays the less-than sign, &gt; displays the greater-than sign, and &amp; displays an ampersand.

Common HTML entity uses

  • Display code snippets safely on a web page.
  • Escape user-generated content before it is rendered.
  • Convert between named entities and their raw characters.

FAQ

What is an HTML entity?

An HTML entity is a code that represents a reserved or special character in HTML, such as &lt; for the less-than sign.

Why encode HTML entities?

Encoding HTML entities prevents browsers from treating characters like < and > as markup, which helps display code and avoid HTML injection.

What is the difference between named and numeric entities?

Named entities use a word like &lt;, while numeric entities use a number like &#60;. Both represent the same character.
