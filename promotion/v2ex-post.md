# [分享] 做了个在线工具站 always.tools，14 个工具，纯前端零后端求拍砖

花了两周时间撸了个在线工具箱，已经上线 14 个工具：

## 编码转换
- JSON 格式化/校验/压缩
- Base64 编解码（支持文本和文件）
- URL 编解码
- HTML 实体编解码
- Unicode 转换

## 开发工具
- 正则表达式测试（实时匹配高亮）
- 时间戳转换（双向 + 实时时钟）
- 哈希生成（SHA-1/256/384/512）
- UUID v4 批量生成

## 日常工具
- 二维码生成（可下载 PNG）
- 图片压缩（纯浏览器端 Canvas）
- 颜色转换（HEX/RGB/HSL 联动 + 取色器）
- 字数统计（支持中英文混合）
- 摩斯密码（可播放音频）

## 特点
- 纯静态 HTML，没有任何后端
- 所有处理都在浏览器端，无隐私问题
- Cloudflare Pages 托管，全球 CDN
- 代码开源: github.com/super-rick/always-tools
- 每个工具一个独立页面，加载 < 0.5s

- 身份证校验
- 人民币大写转换
