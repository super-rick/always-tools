## 为什么是工具站

工具站模式：用工具捕获搜索意图 → SEO 排名 → 自然流量 → 广告变现。不需要用户注册、不需要付费转化、不需要客服。

**已验证的案例**：tool.lu（月入 ¥50 万+）、json.cn（日 PV 50 万）、sojson.com（月入 ¥30 万+）——全是静态工具，没有一个需要后端。

## 技术选型

托管：Cloudflare Pages（免费不限流量）
域名：always.tools（$28/年）
前端：纯 HTML/CSS/Vanilla JS（零框架依赖）
广告：Google AdSense（待审核）

**为什么纯静态？** 不需要服务器、不需要运维、不需要数据库、不需要备份。

**为什么不用框架？** React/Vue 首屏 2-3 秒，纯 HTML 首屏 < 0.5 秒。

## 工具选择策略

核心原则：**每个工具 = 一个高频搜索关键词**

| 梯队 | 工具 | 日搜索量 |
|:--|:--|:--|
| 🥇 高流量 | JSON格式化 / Base64 / 二维码 / 时间戳 | 2-10万+ |
| 🥈 中等流量 | 图片压缩 / 正则测试 / 颜色转换 / 哈希 | 1-5万 |
| 🥉 长尾 | 字数统计 / HTML实体 / Unicode / 摩斯 | 1000-1万 |

14 个工具 × 每个覆盖 5-10 个关键词 = **100+ 长尾关键词**
